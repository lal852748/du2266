# 데스크 심판관

웹소설 플랫폼의 **신입 PD**가 되어 14일 동안 쏟아지는 투고 원고와 돌발 사건을 결재하는 카드 결재 시뮬레이션 게임입니다.
트래픽 · 자금 · 멘탈, 세 지표 중 하나라도 0이 되거나 트래픽이 100을 넘으면 그날로 퇴근(게임 오버)!

## 플레이

- 브라우저에서 `desk_judge.html`을 열면 바로 시작합니다. 설치할 것이 없습니다.
- GitHub Pages를 켰다면 저장소의 Pages 주소로 접속하세요.

## 조작

| 동작 | 마우스 / 터치 | 키보드 |
|---|---|---|
| 연재 승인 | 카드를 오른쪽으로 밀기 · 버튼 | `1` |
| 반려 | 카드를 왼쪽으로 밀기 · 버튼 | `2` |
| 제목 어그로 수정 (50% 도박) | 카드를 위로 밀기 · 버튼 | `3` |
| 아이템 (에너지 드링크 · 서버 증설권 · 심연 투시경) | 아이템 버튼 | `Q` `W` `E` |
| 다음 카드 | 결과 카드 탭 · 스와이프 | `Enter` `Space` `→` |
| 퇴근 (저장하고 나가기) | 🚪 퇴근 버튼 | `Esc` |
| BGM / 효과음 | 상단 버튼 | `B` / `M` |

## 주요 기능

- 투고 원고 · 돌발 이벤트 시나리오 50종, 한 판(37장)에서 같은 카드가 다시 나오지 않음
- 3일마다 바뀌는 메인 · 서브 트렌드와 콤보 보너스
- 일차별 난이도 상승 (15초 → 12초 → 9초)
- 엔딩 6종 · 최종 점수와 인사평가 등급 (S+ ~ F)
- 누적 커리어: 결재가 쌓이면 신입 PD에서 편집장까지 승진, 직급별 출근 보너스
- 업적 19종 (숨은 업적 포함)
- 외부 이미지 · 음원 파일 없이 HTML/CSS/JavaScript와 Web Audio API만으로 제작

기록(커리어 · 업적 · 최고 기록 · 저장)은 플레이하는 사람의 브라우저에 저장됩니다.
